# Архитектура

## Компоненты

| Компонент | Код | Где работает | Что делает |
|---|---|---|---|
| Плагин Revit | `plugin/RevitAIClassifier` (C#) | у каждого пользователя | маппинг параметров, сбор признаков, окно проверки, запись, отчёт |
| Сервис | `python/service.py` (FastAPI) | один на компанию, Docker | применяет правила, справочник и модели, принимает правки |
| Программа обучения | `python/app.py` (tkinter) | у BIM-менеджера | IFC → разметка, проверка моделей, метрики, правки коллег |
| Таблица правил | `rules/Правила_АГР.xlsx` | в `deploy/data/rules.xlsx` | экспертные правила, порядок параметров, классификаторы |

## Порядок определения значения (сервис)

Параметры заполняются в порядке листа «Параметры». Для каждого:

1. значение, подтверждённое пользователем на предыдущем шаге (`fixed`) — не меняется;
2. правило с «Как применять» = *правило* — уверенность 1.0;
3. справочник — точно такой тип/помещение уже размечен;
4. правило «сверить с моделью» — если модель не согласна, значение уходит на проверку;
5. модель (код «Элементы», параметры помещений и зон) — «ок» при уверенности ≥ `CONF_OK` (0.95);
6. для кода помещения — точное совпадение имени с классификатором.

Наименования (`*_Name`) берутся из классификатора по коду.
Режим `AGR_MODE=rules|model` отключает обучение или правила — для экспериментов.

## Признаки, которые плагин передаёт сервису

`file` (имя файла Revit → тип файла: план / паркинг / фасад), `facade_type`, `revit_category`,
`ifc_class`, `parent_class`, `in_curtain_wall`, `is_curtain_wall`, `type_full`, `materials`, `layers_mm`,
`IsExternal`, `has_door_leaf`, `room_from`, `room_to`, `in_place`; у помещений и зон —
`space_name`, `space_purpose`, `apartment_number`, `space_number`, `level`, `area_scheme`, `zone_type`,
`zone_has_apartments`, `level_has_apartments`.

## Модели

- **Код «Элементы»** (`python/train_model.py`): TF-IDF по словам и символам имени типа и материалам,
  one-hot категории/класса/флагов, пороги толщины → `LogisticRegression(class_weight="balanced")`.
  Выбор ограничен кодами, встречавшимися у того же IFC-класса.
- **Помещения и зоны** (`python/train_spaces.py`): символьные n-граммы имени, назначение, вид, тип зоны.

Обе обучаются при старте сервиса и при изменении таблиц (автоперезагрузка раз в 30 с).

## API сервиса

| Метод | Путь | Что |
|---|---|---|
| GET | `/health` | состояние, режим, время загрузки, последняя ошибка |
| GET | `/classifiers` | классификаторы, описания параметров, порядок |
| POST | `/predict_all` | `{items: [{id, features, fixed}]}` → значения по всем параметрам |
| POST | `/corrections` | правки пользователей → `corrections.csv` |
| POST | `/reload` | перечитать таблицы |
