АтрибутыАГР

Плагин для Revit, который заполняет параметры для выдачи IFC на АГР в Москве: класс IFC, коды МССК, RUS_Name, материалы, помещения и зоны. Правила вы ведёте в Excel, а там, где правил нет, работает модель, обученная на ваших уже выданных IFC.

Что заполняет

Заполнение идёт по шагам: сначала класс IFC, потому что от него зависит, из каких кодов вообще можно выбирать. Исправление на одном шаге учитывается в следующих.

Класс IFC

IfcExportAs по категории, типу файла и фасада

Коды МССК

«Элементы», «Строительные изделия и материалы», «Помещения и зоны»

RUS_Name

по единой схеме названий для всех категорий

Материалы

код и наименование по классификатору материалов

Помещения и зоны

код, зона, этажи, студия, жилая или нежилая

Прочее

толщина по слоям, исключение лишних элементов, размеры по маппингу

Как устроено

Три части. Пользователям нужен только плагин, сервис ставится один раз на сервер компании, программа обучения — у BIM-менеджера.

Установка

Установщик и программа обучения доступны на странице Releases.

1Сервисадминистратор или BIM-менеджер, один раз
  1. Подготовьте компьютер или сервер в сети компании с Docker. Скачайте исходники (Source code) со страницы релиза и распакуйте архив. Скопируйте rules/Правила_АГР.xlsx в deploy/data/rules.xlsx.
  2. Соберите и запустите сервис: 
    cd deploy
docker compose up -d --build
  3. Проверьте в браузере http://<сервер>:8765/health — должно быть "ok": true.
  4. Если с других компьютеров не открывается, разрешите порт (Windows, от администратора): 
    netsh advfirewall firewall add rule name="AtributyAGR 8765" dir=in action=allow protocol=TCP localport=8765

Без обучения тоже работает. Пока нет разметки, сервис заполняет всё, что покрывают правила, а остальное отправляет на проверку. Модель подключится, когда вы положите labels.xlsx в папку data.

2Плагинкаждый пользователь Revit
  1. Закройте Revit.
  2. Скачайте и запустите AtributyAGR_Revit2020-2026_Setup_<версия>.exe. Права администратора не нужны, плагин встанет во все найденные версии Revit.
  3. Укажите адрес сервера, например http://10.0.0.10:8765. Его даёт тот, кто ставил сервис.
  4. Откройте Revit — появится вкладка АтрибутыАГР. Новая версия ставится поверх, настройки сохраняются.

Windows может предупредить, что запуск предотвращён: установщик не подписан цифровой подписью. Нажмите «Подробнее», затем «Выполнить в любом случае». Скачивайте только со страницы Releases репозитория.

3Программа обученияBIM-менеджер, по желанию
  1. Скачайте AtributyAGR_Trainer_<версия>.zip, распакуйте и запустите AtributyAGR_Trainer.exe. Таблица правил и классификаторы уже внутри.
  2. Как обучить модель на своих IFC — в разделе Обучение.

Работа в Revit

  1. Настройте маппинг

    Слева категории, справа соответствие параметр АГР ↔ параметр Revit, с поиском и выбором тип/экземпляр. «Перезаписывать» решает, менять ли уже заполненное. Настройки экспортируются и передаются коллегам.

  2. Выберите тип фасада и область

    Весь документ или только видимое на активном виде. Тип фасада влияет на класс и коды.

  3. Нажмите «Заполнить параметры»

    Откроется окно проверки с вкладками по шагам. Строки «проверить» стоят вверху, у каждого значения видны источник и уверенность.

  4. Поправьте и пересчитайте

    Выберите другой код с поиском по классификатору, затем «Пересчитать следующие шаги».

  5. Запишите в Revit

    После записи можно выгрузить отчёт в Excel с ID элементов: что заполнено и почему что-то нет.

Таблица правил

Правила — обычный Excel: rules/Правила_АГР.xlsx, на сервере — data/rules.xlsx. Одна строка — одно правило. Если выполнены все заполненные условия, параметр получает значение. Сервис подхватывает изменения примерно за 30 секунд, пересобирать ничего не нужно.

правило

Однозначный случай, значение пишется сразу.

правило, сверить с моделью

Если модель не согласна, значение уходит на проверку.

только обучение

Код разрешён, но решает модель по выданным IFC.

Как записать условие

Пустая ячейка — «неважно». Варианты через запятую, ! — «НЕ», гкл+перегородк — обе части сразу. Условия: категория, тип файла и фасада, имя типа, материал, толщина, витраж, створка с дверью, помещения по обе стороны двери, условие по параметру. Меньший приоритет срабатывает раньше.

Удобно сначала разложить логику схемой, как справа, а потом перенести ветки в таблицу.

Обучение на выданных IFC

Модель учится на ваших уже выданных и принятых IFC: подбирает коды для типов, которых нет в правилах. Это необязательно, но чем больше разметки, тем меньше ручной проверки.

  1. Обработайте IFC

    Выберите выданные IFC, классификатор элементов и папку результата, нажмите «Обработать». Получите labels.xlsx и labels_spaces.xlsx.

  2. Разберите спорное

    Строки «проверить» и «конфликт» — места, где выданные IFC расходятся с правилами или между собой.

  3. Проверьте качество

    «Проверить модель», «Сравнить подходы» (правила / модель / гибрид) и «Контрольные IFC» — проверка на объектах, которых нет в разметке.

  4. Отдайте сервису

    Скопируйте таблицы в data на сервере, сервис переобучится сам.

  5. Собирайте правки

    «Правки коллег…» добавляет исправления пользователей в разметку со статусом «проверить».

Вопросы

Данные проекта куда-то уходят?

Нет. Сервис работает в вашей сети, на вашем сервере. Плагин отправляет признаки элементов только на этот адрес, внешних API и облака нет.

Нужна ли видеокарта или мощный сервер?

Нет. Используется логистическая регрессия: обучение занимает секунды на обычном компьютере, GPU не нужен.

Почему не языковая модель?

Данных — сотни типов, а ответ выбирается из закрытого списка кодов, допустимых для класса IFC. Языковая модель может выдумать несуществующий код, а вероятностям логистической регрессии можно доверять: на них построены статусы «ок» и «проверить».

Сервис доступен извне. Как защитить?

Оставьте сервис во внутренней сети. Для удалённого доступа используйте VPN или обратный прокси с HTTPS. Задайте AGR_TOKEN в Docker Compose и укажите тот же токен в настройках плагина.

Можно ли без модели, только по правилам?

Да: AGR_MODE: rules. Есть и обратный режим model, по умолчанию — hybrid.

Порт 8765 занят

Поменяйте левое число в ports, например "8770:8765", и адрес в плагине.

Нашли ошибку или хотите предложить правило

Создайте Issue в репозитории: есть шаблоны для ошибки и для нового правила.
