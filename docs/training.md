# Обучение, разметка, метрики

Программа обучения — `python/app.py` (или exe из релизов). Работает у BIM-менеджера;
всем пользователям её ставить не нужно.

```bash
cd python
pip install -r requirements.txt
python app.py
```

Сборка exe: `python/build_exe.bat` → `python/dist/AtributyAGR_Trainer/AtributyAGR_Trainer.exe`.

## Разметка из выданных IFC

1. Выберите IFC (файлы или папку), классификатор элементов (`rules/classifiers/…Элементы….txt`),
   папку результата. Положите туда свою таблицу правил и прежнюю разметку — правки сохранятся.
2. **«Обработать»** → `labels.xlsx` (элементы) и `labels_spaces.xlsx` (помещения и зоны).
   IFC читаются параллельно, повторно — из кэша.
3. Разберите строки «проверить» / «конфликт» (жёлтые колонки — ваши правки).
4. Скопируйте таблицы в `deploy/data` на сервере — сервис переобучится сам.

## Проверка и метрики

| Кнопка | Что показывает |
|---|---|
| «Проверить модель» | точность моделей на незнакомых типах/именах, калибровка уверенности, `errors_*.csv` |
| «Сравнить подходы» | только правила / только модель / гибрид на одних данных → `compare_report.xlsx` |
| «Контрольные IFC…» | честная проверка на отложенных объектах (в разметку не попадают) → `control_report.xlsx` |

Главные метрики: **точность автоматических** (можно ли доверять тому, что пишется без проверки)
и **ошибок без проверки**. Лист «Пороги уверенности» помогает выбрать `CONF_OK`.

Контрольные IFC: готовые, правильно заполненные IFC **других объектов**, которых нет в разметке
и под которые не подгонялись правила.

## Правки коллег

Плагин отправляет исправленные и подтверждённые значения на сервер (`data/corrections.csv`).
«Правки коллег…» → выберите этот файл: код «Элементы» и параметры помещений попадут в разметку
со статусом «проверить», остальное — в `corrections_report.xlsx`. Отклонить правку навсегда:
оставьте свой код, статус «проверено» и комментарий.

## Классификаторы МССК

В `rules/classifiers/` — текстовые версии (код, наименование, уровень; UTF-16).
Обновить из PDF exp.mos.ru: `python tools/mssk_pdf_to_txt.py <pdf> <txt> [--drop-last-column]`.
