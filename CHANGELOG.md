# Изменения

## 1.4.0

- Плагин для **Revit 2020–2026**: один код, сборки под .NET Framework 4.7/4.8 и .NET 8
  (`build_all.bat`, параметр `RevitVersion`); RevitAPI из установленного Revit или из NuGet.
- Один установщик на все версии: ставит плагин во все найденные Revit.
- CI собирает плагин под все семь версий; релиз — установщик со всеми сборками.

## 1.3.0 — первая публичная версия

- Плагин Revit 2022 «АтрибутыАГР»: маппинг параметров АГР по категориям (поиск, тип/экземпляр,
  галочки, перезапись), окно проверки по шагам схемы (IfcExportAs → классификатор → группа модели →
  материалы → прочее), группировка помещений и моделей в контексте, отчёт в Excel с ID элементов.
- Сервис (FastAPI, Docker): таблица правил + справочник + модели, автоперезагрузка таблиц,
  режимы `hybrid` / `rules` / `model`, журнал правок, токен доступа.
- Программа обучения: разметка элементов и помещений из IFC, проверка моделей,
  сравнение подходов, проверка на контрольных IFC, сбор правок коллег.
- Таблица правил с классификаторами МССК; конвертер классификаторов из PDF.
