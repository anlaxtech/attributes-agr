# АтрибутыАГР

**Заполнение параметров АГР в Revit по правилам и машинному обучению.**

АтрибутыАГР подбирает для элементов модели Revit значения параметров, которые нужны для выдачи
IFC по требованиям АГР: класс IFC (`IfcExportAs`), коды классификаторов МССК («Элементы»,
«Строительные изделия и материалы», «Помещения и зоны»), группу модели (`RUS_Name`), материалы,
параметры помещений и зон. Экспертные правила записываются в обычную таблицу Excel, а там,
где правил нет, работает модель, обученная на уже выданных IFC. Всё сомнительное человек
проверяет в окне плагина до записи в модель.

> English: AtributyAGR fills Russian AGR/MSSK IFC parameters in Revit using an editable rule table
> plus models trained on previously issued IFC files. Revit 2020–2026 add-in (C#) + FastAPI service
> (Docker) + training app (Python). Documentation is in Russian.

## Как это устроено

```
 Выданные IFC ──► Программа обучения ──► labels.xlsx, labels_spaces.xlsx ─┐
                  (python/app.py)                                            │
 Правила_АГР.xlsx (экспертные правила) ─────────────────────────────────────┤
                                                                             ▼
 Revit + плагин АтрибутыАГР ◄──────── HTTP ────────► Сервис АтрибутыАГР (Docker)
 вкладки проверки, запись,                       правила → справочник → модель,
 отчёт в Excel, правки ──────────────────────►   журнал правок пользователей
```

Подробнее — [docs/architecture.md](docs/architecture.md).

## Возможности

- **Пошаговое заполнение по схеме:** IfcExportAs → классификатор → группа модели → материалы → прочее.
  Исправление на шаге учитывается в следующих шагах.
- **Таблица правил в Excel** (`rules/Правила_АГР.xlsx`): условия по категории, имени типа, материалу,
  толщине, типу файла и фасада, помещениям по обе стороны двери, пересечению зон с квартирами и т. д.
  Правила меняются без пересборки плагина и сервиса.
- **Обучение на выданных IFC:** модели для кода «Элементы» и параметров помещений и зон;
  гибрид «правила + модель» с порогом уверенности.
- **Окно проверки в Revit:** вкладки по шагам, поиск по классификатору, группировка помещений
  и моделей в контексте, массовое изменение, отчёт в Excel с ID элементов.
- **Обратная связь:** правки пользователей уходят на сервер и сводятся в разметку
  после проверки BIM-менеджером.
- **Метрики:** сравнение «только правила / только модель / гибрид» и проверка на контрольных IFC.

## Скачать (без сборки)

Готовые файлы — на странице **[Releases](../../releases/latest)**:

| Файл | Для кого | Что сделать |
|---|---|---|
| `AtributyAGR_Revit2020-2026_Setup_<версия>.exe` | все пользователи Revit | закрыть Revit → запустить → указать адрес сервера → вкладка **АтрибутыАГР** |
| `AtributyAGR_Trainer_<версия>.zip` | BIM-менеджер | распаковать → `AtributyAGR_Trainer.exe` (таблица правил и классификаторы уже внутри) |
| Docker-образ `ghcr.io/<владелец>/atributy-agr-service` | администратор сервера | `deploy/docker-compose.image.yml` → `docker compose -f docker-compose.image.yml up -d` |

Установщик ставит плагин во все найденные Revit 2020–2026, права администратора не нужны.
Адрес сервера спросит при установке — его даёт BIM-менеджер или администратор.

> Windows может предупредить «Защитник Windows предотвратил запуск» — файлы не подписаны цифровой
> подписью. Нажмите «Подробнее» → «Выполнить в любом случае». Скачивайте только со страницы Releases этого репозитория.

## Быстрый старт (из исходников)

| Что | Где | Документация |
|---|---|---|
| Сервис (сервер компании, Docker) | `deploy/`, `python/` | [docs/deploy.md](docs/deploy.md) |
| Плагин Revit 2020–2026 и установщик | `plugin/` | [docs/plugin.md](docs/plugin.md) |
| Программа обучения, разметка, метрики | `python/` | [docs/training.md](docs/training.md) |
| Таблица правил | `rules/` | [docs/rules.md](docs/rules.md) |

Самый короткий путь:

```bash
# 1. сервис
cd deploy
mkdir -p data && cp ../rules/Правила_АГР.xlsx data/rules.xlsx
docker compose up -d --build            # → http://<сервер>:8765/health

# 2. плагин — Visual Studio 2022, конфигурация Release (или готовый установщик из Releases)
# 3. обучение — python/app.py: выданные IFC → labels.xlsx → в deploy/data
```

## Структура

```

python/                     сервис (service.py), обучение (app.py), правила, метрики

```

## Безопасность и данные

- Сервис рассчитан на **внутреннюю сеть компании**. Если он доступен извне — задайте `AGR_TOKEN`
  (см. [SECURITY.md](SECURITY.md)).
- Данные проектов (IFC, разметка, журналы правок) **не хранятся в репозитории** — см. `.gitignore`.
- Классификаторы МССК опубликованы на exp.mos.ru; конвертер — `tools/mssk_pdf_to_txt.py`.

## Требования

- Revit 2020–2026 (Windows). Для сборки плагина — .NET SDK 8 (или Visual Studio 2022).
- Docker для сервиса. Python 3.12 для программы обучения.
